# EDY HelpDesk 1.0.1 — Release Notes

EDY HelpDesk 1.0.1 makes the project easier to evaluate and run locally while preserving the audited Service Desk behavior from 1.0.0.

## Highlights

- Redesigned GitHub README with a clearer product overview and four selected synthetic screenshots.
- Professional Portuguese and English README navigation.
- Branded EDY HelpDesk cover and prepared Social Preview asset.
- Streamlined Quick Start for visitors and a separate advanced setup guide.
- Secure Windows launchers for initial setup, supervised startup and scoped shutdown.
- Automatic local generation of demo credentials; no password is published or hardcoded.
